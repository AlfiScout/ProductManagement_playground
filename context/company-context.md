# Make — Company Context

## Overview
Make (formerly Integromat) is a visual automation and AI orchestration platform that enables anyone — technical or not — to design, build, and automate workflows, apps, and systems without writing code. Founded in Prague, Czech Republic, Make is one of the leading no-code/low-code automation platforms globally.

## Mission
Democratize automation. Give every person and business the ability to automate anything, visually, at scale.

## Product Philosophy
- **Visual-first**: Everything is visible, inspectable, drag-and-drop
- **Power without code**: Advanced logic, branching, error handling — all without engineering
- **AI-native**: AI Agents, MCP integration, and AI-powered automation built into the core product
- **Transparency**: Users can see every step, every decision, every data flow

## Core Product
Make's main product is the **Scenario Builder** — a visual canvas where users connect apps and services into automated workflows called *scenarios*.

Key concepts:
- **Scenario**: An automated workflow connecting multiple apps/services
- **Module**: A single action within a scenario (e.g., "Watch new emails", "Create a row in Google Sheets")
- **Connection**: An authenticated link to a third-party app
- **Bundle**: A single unit of data processed by a module
- **Operations (Credits)**: The unit of consumption — each module execution costs operations
- **Organization / Team**: Hierarchy for user and resource management
- **Webhook**: Trigger that starts a scenario via HTTP event

## Key Product Areas
1. **Scenario Builder** — Visual workflow editor
2. **Connections** — 1,800+ app integrations
3. **Observability & Monitoring** — Execution logs, Make Grid, Analytics Dashboard
4. **AI Agents** — Visual agentic workflows with step-by-step transparency
5. **Data Stores** — Built-in lightweight database
6. **Scheduling** — Cron-like scenario scheduling
7. **Error Handling** — Built-in retry, fallback, and alert mechanisms
8. **MCP Server/Client** — Make scenarios as AI-callable tools

## Business Model
- **SaaS subscription** with operation-based pricing tiers (Free, Core, Pro, Teams, Enterprise)
- Revenue tied to operation consumption (module executions)
- Upsell paths: higher operation limits, more users, advanced features, dedicated infra

## Customer Segments
- **SMB / Prosumers**: Marketing, ops, RevOps teams building their own automations
- **Mid-Market**: Teams with dedicated automation owners, 10–200 scenarios active
- **Enterprise**: IT/Ops departments managing hundreds of scenarios, governance needs

## Competitive Landscape
- **Direct**: Zapier (simpler, broader), n8n (open-source, self-hosted), Workato (enterprise)
- **Adjacent**: Power Automate (Microsoft ecosystem), Tray.io, Activepieces
- **AI-native entrants**: Dust, Relay.app, custom LLM orchestration tools
